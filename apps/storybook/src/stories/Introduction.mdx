## How it fits together

- **`@kalads/tokens`**: every colour, size, font and shadow as CSS custom properties, in three layers:
  core values, semantic names (what a value is for) and component tokens.
- **`@kalads/icons`**: SVG icons as `<kds-icon-*>` elements that take the text colour.
- **`@kalads/web-components`**: `<kds-*>` web components built from the tokens. Change a token and every
  component follows.

## Using these docs

- **Designers:** start with Foundations and the Usage section on each component page.
- **Developers:** each component page has a props table (attributes, slots, events and CSS parts) and
  copyable code under every example.
- **AI agents:** read Guidelines/For AI Agents before changing any UI code.
