`@kalads/react-components` or `@kalads/react-native-components`, and icons from `@kalads/icons` (`/react`,

## Usage

- Use a divider to separate groups of content when spacing alone isn't enough. Try spacing first.
- Add `decorative` when the line is purely visual (for example between menu items), so it's hidden from
  screen readers.
- A divider with text labels a break between sections: "or", "Older".

<DoDont>
  <Do caption="One divider between two different groups.">
    <kds-stack gap="md">
      <kds-typography>Profile and account</kds-typography>
      <kds-divider></kds-divider>
      <kds-typography color="danger">Delete account</kds-typography>
    </kds-stack>
  </Do>
  <Dont caption="Don't put a divider between every item: spacing already separates them.">

  </Dont>
</DoDont>
