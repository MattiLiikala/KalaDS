## Usage

- Use a divider to separate groups of content when spacing alone isn't enough. Try spacing first.
- Add `decorative` when the line is purely visual (for example between menu items), so it's hidden from
  screen readers.
- A divider with text labels a break between sections: "or", "Older".

<DoDont>
  <Do caption="One divider between two different groups.">
    <kds-stack gap="md">
