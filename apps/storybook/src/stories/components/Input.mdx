## Code

The same example in each library. Components come from `@kalads/web-components`,
`@kalads/react-components` or `@kalads/react-native-components`, and icons from `@kalads/icons` (`/react`,
`/native`). React and React Native take the same props in camelCase, callbacks for events (`onChange` for
`kds-change`) and props for named slots (`start`, `footer`).

## Usage

- Always set a `label`. It stays visible above the field and is the field's accessible name.
- Use `helper` for format or limits, and `error` to say what's wrong and how to fix it. The error
  replaces the helper while it's shown.
- Pick the matching `type` (`email`, `tel`, `url`…) so phones show the right keyboard.
- Size the field to the expected answer: a postcode field doesn't need the full width.

<DoDont>
  <Do caption="A visible label, with the format in the helper text.">

  <Dont caption="Don't use the placeholder as the label: it disappears as soon as people type.">
