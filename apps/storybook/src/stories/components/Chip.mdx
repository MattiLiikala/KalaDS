## Code

The same example in each library. Components come from `@kalads/web-components`,
`@kalads/react-components` or `@kalads/react-native-components`, and icons from `@kalads/icons` (`/react`,
`/native`). React and React Native take the same props in camelCase, callbacks for events (`onChange` for
`kds-change`) and props for named slots (`start`, `footer`).

## Usage

- Use chips for filters (`selectable`), entered values such as tags or recipients (`removable`), or
  static tags.
- Keep labels short and lay chips out in a wrapping row (`kds-stack direction="row" wrap`).
- Chips aren't buttons: for actions use `kds-button`.

<DoDont>
  <Do caption="Selectable chips as filters in a wrapping row.">
    <kds-stack direction="row" gap="sm" wrap>
      <kds-chip selectable selected>All</kds-chip>
      <kds-chip selectable>Open</kds-chip>
      <kds-chip selectable>Closed</kds-chip>
    </kds-stack>
  </Do>
  <Dont caption="Don't use a chip as a call to action: use a button.">
    <kds-chip selectable variant="primary">Buy now</kds-chip>
  </Dont>
</DoDont>
