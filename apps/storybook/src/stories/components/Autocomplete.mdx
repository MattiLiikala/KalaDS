## Code

The same example in each library. Components come from `@kalads/web-components`,
`@kalads/react-components` or `@kalads/react-native-components`, and icons from `@kalads/icons` (`/react`,
`/native`). React and React Native take the same props in camelCase, callbacks for events (`onChange` for
`kds-change`) and props for named slots (`start`, `footer`).

## Usage

- Use an autocomplete when there are many options (more than about 15) and people know what they're
  looking for, such as a country or a colleague. For shorter lists use `kds-select` or a radio group.
- Options are `<option>` children. The field filters them as people type.
- Set `empty-text` to say what to do when nothing matches.

<DoDont>
  <Do caption="A long list that people search by name.">
    <kds-autocomplete label="Country" placeholder="Start typing">
      <option value="fi">Finland</option>
      <option value="fr">France</option>
      <option value="de">Germany</option>
      <option value="gr">Greece</option>
    </kds-autocomplete>
  </Do>
  <Dont caption="Don't use an autocomplete for a handful of options: a radio group shows them all at once.">
    <kds-autocomplete label="Size">
      <option value="s">Small</option>
      <option value="m">Medium</option>
      <option value="l">Large</option>
    </kds-autocomplete>
  </Dont>
</DoDont>
