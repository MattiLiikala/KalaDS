## Usage

- Use `kds-icon` for standalone icons with KalaDS sizes and colours, or when the name comes from data.
- Pair icons with text. An icon alone only works for universally known symbols.
- Give an icon a `label` only when it carries meaning on its own; icons next to text are decorative.

<DoDont>
  <Do caption="Icon and text together: the colour adds emphasis, the text carries the meaning.">
    <kds-stack direction="row" gap="xs" align="center">
      <kds-icon name="check-circle" color="success"></kds-icon>
      <kds-typography>Saved</kds-typography>
    </kds-stack>
  </Do>
  <Dont caption="Don't rely on an icon's colour alone to show status.">
    <kds-icon name="error" color="danger" size="lg"></kds-icon>
  </Dont>
</DoDont>
