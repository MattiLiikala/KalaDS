## Usage

- Use a card for one self-contained thing: a project, a person, a summary. Use `kds-paper` for a plain
  surface without header and footer sections.
- Keep one elevation for cards that sit side by side. Raise a card only to show it's more important.
- An `interactive` card must be wrapped in a link so it can be reached with the keyboard. Put at most one
  main action in the footer.
