## Usage

- Use a dialog for a short, focused task or a decision people must make before going on.
- `heading` names the task ("Delete project?") and is the dialog's accessible name.
- Put the actions in the `footer` slot: a ghost button to back out, then the main action, labelled with what
  it does.
- Use `persistent` only when a choice is required: it removes the close button and Escape.
