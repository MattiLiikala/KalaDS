## Code

The same example in each library. Components come from `@kalads/web-components`,
`@kalads/react-components` or `@kalads/react-native-components`, and icons from `@kalads/icons` (`/react`,
`/native`). React and React Native take the same props in camelCase, callbacks for events (`onChange` for
`kds-change`) and props for named slots (`start`, `footer`).

## Usage

- Use a drawer for navigation or a secondary task that keeps the page in view, such as filters or details.
- `placement` sets the side (`start` or `end`) and `size` the width.
- Like a dialog, a drawer is modal: focus stays inside and Escape closes it. Use `persistent` only when a
  choice is required.
- For a short decision, use `kds-dialog`.
