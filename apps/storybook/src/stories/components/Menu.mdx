`@kalads/react-components` or `@kalads/react-native-components`, and icons from `@kalads/icons` (`/react`,
`/native`). React and React Native take the same props in camelCase, callbacks for events (`onChange` for

## Usage

- Use a menu for a list of actions behind one trigger, usually a button or an icon button.
- Put destructive actions last, after a decorative divider, with `variant="danger"`.
- For choosing a value, use `kds-select`. For one or two actions, show them as buttons.
