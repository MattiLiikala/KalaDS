## Code

The same example in each library. Components come from `@kalads/web-components`,
`@kalads/react-components` or `@kalads/react-native-components`, and icons from `@kalads/icons` (`/react`,
`/native`). React and React Native take the same props in camelCase, callbacks for events (`onChange` for
`kds-change`) and props for named slots (`start`, `footer`).

## Usage

- Use a link to go somewhere. For actions on the page, use `kds-button`.
- Link text says where it goes: "Read the billing guide", not "click here".
- Use `target="_blank"` only when leaving would lose work; the link then shows an icon and tells screen
  readers it opens a new tab.

<DoDont>
  <Do caption="Link text that makes sense on its own.">
    <kds-typography>Read the <kds-link href="#">billing guide</kds-link> to change your plan.</kds-typography>
  </Do>
  <Dont caption="Don't use vague link text: 'here' says nothing out of context.">
    <kds-typography>To change your plan, click <kds-link href="#">here</kds-link>.</kds-typography>
  </Dont>
</DoDont>
