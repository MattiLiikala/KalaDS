## Usage

- Use a grid for two-dimensional layouts: cards, tiles, form columns.
- `min` gives a responsive grid without breakpoints: as many columns as fit, each at least that wide.
  Use `columns` for a fixed count.
- For a single row or column, use `kds-stack`.
