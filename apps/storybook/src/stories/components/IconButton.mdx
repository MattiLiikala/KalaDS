## Code

The same example in each library. Components come from `@kalads/web-components`,
`@kalads/react-components` or `@kalads/react-native-components`, and icons from `@kalads/icons` (`/react`,
`/native`). React and React Native take the same props in camelCase, callbacks for events (`onChange` for
`kds-change`) and props for named slots (`start`, `footer`).

## Usage

- Use an icon button only for actions with a widely understood icon: close, search, more, menu.
  Everything else gets a text button.
- `label` is required: it's the accessible name. Add a `kds-tooltip` with the same text for sighted users.
- The default `ghost` variant suits toolbars and headers. Solid variants follow the surface rules in
  **Guidelines/Buttons and Surfaces**.
