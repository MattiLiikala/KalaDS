## Usage

- Use an icon button only for actions with a widely understood icon: close, search, more, menu.
  Everything else gets a text button.
- `label` is required: it's the accessible name. Add a `kds-tooltip` with the same text for sighted users.
- The default `ghost` variant suits toolbars and headers. Solid variants follow the knockout rules in
  **Guidelines/Knockout and Surfaces**.
