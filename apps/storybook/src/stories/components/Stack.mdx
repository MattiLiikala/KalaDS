## Usage

- Use a stack to lay out children in one row or column with even spacing from the scale.
- `direction="row"` with `wrap` for button groups and chips, `justify="end"` for form actions.
- For two-dimensional layouts, use `kds-grid`.

      <kds-button variant="ghost">Cancel</kds-button>
      <kds-button>Save</kds-button>
    </kds-stack>
  </Do>
</DoDont>
