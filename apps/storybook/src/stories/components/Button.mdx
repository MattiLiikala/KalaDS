## Code

The same example in each library. Components come from `@kalads/web-components`,
`@kalads/react-components` or `@kalads/react-native-components`, and icons from `@kalads/icons` (`/react`,

## Usage

- Use **one primary button** per view or section, for the main action. Use `secondary` for other
  important actions and `ghost` for the rest (cancel, back, less important choices).
- Use `danger` only for actions that destroy something, and say what will be destroyed: "Delete project".
- Use a button for actions. To go somewhere else, use `kds-link`.
- Solid buttons need a surface their fill stands out from: check **Guidelines/Buttons and Surfaces**
  before placing one on anything other than a light surface.
