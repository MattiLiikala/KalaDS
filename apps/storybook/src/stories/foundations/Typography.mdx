# Typography

Two typefaces:

- **Overlock** for headings and body text: warm and rounded.
- **Parkinsans** for labels, buttons, overlines and other UI text.

Apps load both from `@fontsource/overlock` and `@fontsource/parkinsans`: Overlock 400 and 700,
Parkinsans 300, 400, 500 and 700.

## Type scale

Use `kds-typography` with a `variant`, or the `semantic.type.<variant>.*` tokens in component CSS.
Every value comes from the tokens below.
