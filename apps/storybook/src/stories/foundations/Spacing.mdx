# Spacing and sizes

One size scale feeds all spacing, padding, corner radius, border widths and layout widths. Use the
semantic names in product code; they say what a value is for.

## Core size scale

Every step has a **rem** and a **px** value. Use rem for anything that should grow with the user's font
size (spacing, padding, radius). Use px where a size must stay fixed, such as borders and crisp shadows.
The 25, 50 and 75 steps are hairlines for borders.
