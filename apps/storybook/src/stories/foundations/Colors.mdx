# Colors

Colour tokens come in two layers. **Semantic tokens** (`semantic.*`) name a colour by its job, such as a
page background, body text or a danger border. **Palettes** (`color.*`, the core tokens) are the raw
scales the semantic tokens point to.

**Use only semantic tokens** in your code, in components, layouts and docs alike. They keep their meaning
in both themes, while a palette step stays the same colour and breaks in one of them. Semantic tokens for
data visualisation (charts, data grids) will come in a later release.

## Palettes

The core scales behind the semantic tokens, for reference. They are the same in both themes.

Where a swatch has a label, it shows what the colour can carry on the default page background: **Text**
passes 4.5:1 for body text, **UI** passes 3:1 for borders, icons and large text.
