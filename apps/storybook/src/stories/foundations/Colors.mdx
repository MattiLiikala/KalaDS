# Colors

Colour tokens come in two layers. **Semantic tokens** (`semantic.*`) name a colour by its job, such as a
page background, body text or a danger border. **Palettes** (`color.*`, the core tokens) are the raw
scales the semantic tokens point to.

**Use only semantic tokens** in your code, in components, layouts and docs alike. They keep their meaning
in both themes, while a palette step stays the same colour and breaks in one of them. Semantic tokens for
data visualisation (charts, data grids) will come in a later release.

## Semantic tokens

The tokens to use in your code. Each table lists the palette step a token uses in the light and the dark
theme (see **Guidelines/Dark Mode**).

### Naming

A semantic colour's name says what it colours, then what for: **property-concept-variant-state-mode**.

<table className="kds-docs-table">
  <thead><tr><th>Part</th><th>Values</th></tr></thead>
  <tbody>
    <tr><td>property</td><td><code>bg</code>, <code>text</code>, <code>border</code>, <code>ring</code> (the focus ring)</td></tr>
    <tr><td>concept</td><td><code>interactive</code> (buttons, controls, selection), <code>status</code>, or none for page surfaces and text</td></tr>
    <tr><td>variant</td><td>none for the brand colour, <code>secondary</code>, <code>danger</code>, <code>control</code>; for status <code>danger</code>, <code>warning</code>, <code>success</code>, <code>info</code></td></tr>
    <tr><td>emphasis</td><td><code>subtle</code>, <code>strong</code></td></tr>
    <tr><td>state</td><td><code>hover</code>, <code>active</code>, <code>focus</code>, <code>disabled</code></td></tr>
    <tr><td>mode</td><td><code>on-inverse</code>: for components on an inverse surface</td></tr>
  </tbody>
</table>

For example `bg-interactive-hover` (the brand fill, hovered), `bg-interactive-secondary-active`,
`border-status-danger` and `ring-interactive-focus-on-inverse`. A label on an interactive fill is
`text-on-interactive` (any solid fill) or `text-on-interactive-subtle` (the subtle one).

## Palettes

The core scales behind the semantic tokens, for reference. They are the same in both themes.

Where a swatch has a label, it shows what the colour can carry on the default page background: **Text**
passes 4.5:1 for body text, **UI** passes 3:1 for borders, icons and large text.
