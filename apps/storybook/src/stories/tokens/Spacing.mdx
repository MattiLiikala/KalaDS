# Spacing & Size Tokens

All spacing is based on a **16px root** scale. Core size tokens are mapped to semantic names for
spacing, padding, and border-radius.

---

## Core Size Scale

| Token | CSS Var | Value |
|---|---|---|
| `size.0` | `--kds-size-0` | 0rem |
| `size.100` | `--kds-size-100` | 4px (0.25rem) |
| `size.200` | `--kds-size-200` | 8px (0.5rem) |
| `size.300` | `--kds-size-300` | 12px (0.75rem) |
| `size.400` | `--kds-size-400` | 16px (1rem) |
| `size.500` | `--kds-size-500` | 24px (1.5rem) |
| `size.600` | `--kds-size-600` | 32px (2rem) |
| `size.700` | `--kds-size-700` | 48px (3rem) |
| `size.800` | `--kds-size-800` | 64px (4rem) |
| `size.900` | `--kds-size-900` | 96px (6rem) |

---

## Semantic Spacing

| Token | CSS Var | Core Alias |
|---|---|---|

| `semantic.spacing.sm` | `--kds-semantic-spacing-sm` | size.200 (8px) |
